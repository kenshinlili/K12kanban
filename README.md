## 一分钟了解

围绕**错题**运转的三方协作学习管理系统：

```
孩子打卡 → AI 识别 → 家长审核 → 自动排复习 → 按知识点定位薄弱点
```

使用者只有三个人：爸爸（主导）、妈妈（接手流转）、李迦一（自己打卡复习）。

## 💻 本地开发与接管

**本机可以直接跑起来继续开发**，无需额外配置：

```cmd
双击 start.bat  →  访问 http://localhost:3000
```

| 项目 | 说明 |
|---|---|
| **项目源码** | `kanban/`（Flask + SQLite，路径全部相对定位，拷到任何位置都能跑） |
| **完整指南** | [本地开发指南](本地开发指南.md)（环境搭建、开发流程、数据库操作、常见问题） |
| **数据库** | `kanban\data\kanban.db`（单文件，复制即备份。当前含 3 道测试错题） |
| **依赖** | `pip install -r kanban/requirements.txt`（只需 Flask + pypinyin） |

> ⚠️ 本地与线上**数据不互通**。本地随便造数据、随便改，不影响日常使用；调好了再同步代码发布。
