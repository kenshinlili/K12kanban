# 李迦一 K12 学习看板 · 使用说明

> 一份给爸爸、妈妈、迦一自己看的小手册。看完这一篇，就能上手整套系统。

---

## 1. 系统是什么

一个**三方协作的学习管理看板**，围绕三条主线运转：

| 主线 | 干什么 | 谁主要用 |
|---|---|---|
| **今日打卡** | 记录每天做了什么作业，多长，错题交给 AI 整理 | 迦一自己 |
| **错题本** | 所有错题永久存档，按单元/知识点归类，自动安排复习 | 爸妈查阅 |
| **复习机制** | 错题入库后 2/7/30/30 天自动出现在「复习」页签，错就重置，对就推进 | 爸妈判对错 |

附带的还有：

- **热力图** — 一眼看出哪个单元/知识点错最多
- **学习计划** — 期末前根据薄弱点自动生成每日学习清单
- **流转** — 不会/没空判的题可以甩给另一位家长处理

---

## 2. 四种角色

- 👨 **爸爸** — 主导操作，主要在 PC 端 WorkBuddy
- 👩 **妈妈** — 流转接手，主要在 PC 端 WorkBuddy
- 👧 **李迦一** — 自己打卡、复习，主要在手机/平板浏览器
- 🤖 **AI 助手** — 帮识别作业照片 + 整理错题

顶部三个头像 = 切换身份。系统会记住每个人的操作日志。

---

## 3. 四个页签

### 📋 今日看板
- 顶部日期 + 前后日快捷 + 「今天」按钮
- 8 个板块按科目排列：语文（校内精练/听写/作文/学而思）、数学（校内/校外）、英语（校内/校外）
- 每张卡三种状态：
  - **未打卡**：☐ 今日完成 / — 今日无任务
  - **已打卡**：✓ 已完成（带绿勾）+ 查看详情 / 去处理
  - **无任务**：— 今日无任务
- 每张卡都有 `↩ 返回` 防误点

### 🔁 复习
- **今日待复习**：该判对的题，家长判对/错，答对推进到下一阶段，答错重置
- **今日已复习**：今天做过的所有题，含日期和结果（点完不会消失！）
- 每张复习卡有 `👁 看答案` 折叠 + `↩ 撤销本次` 防误判
- 复习节奏：
  - 语文/英语：错题入库后第 2/7/30/30 天各复习 1 次
  - 数学：错题入库后第 1/30 天各复习 1 次
  - 答满次数自动标「🎉 已掌握」

### ❌ 错题本
- **概览**：错题总数、待复习、复习中、已掌握
- **按单元/知识点归类**：语文按单元，数学英语按主题，点哪个就筛出哪组
- **错误类型分布**：横向条形图，看哪种错最多（前后鼻音不分？同音形近字？）
- **检索**：支持按科目 + 复习状态 + 知识点三重筛选
- 永久保存，**已掌握的题也在**，期末可筛出来看

### 🧠 知识点
- 三个子页签：
  - **🔧 知识点台账** — 维护第一单元～第八单元、大数的认识、Unit 1～6 等
  - **🔥 知识点热力图** — 色块颜色越红=越薄弱，点击跳到错题本
  - **🗓 学习计划** — 薄弱点 TOP 5 + 未来 7 天复习日历

## 4. 标准流程

### 4.1 日常作业（每天）

```
迦一完成作业
   ↓
打开看板 → 点 ☑ 今日完成
   ↓
拍照上传作业照片
   ↓
状态：待识别（🔵）
   ↓
在 WorkBuddy 对话里 @助手：识别一下今天上传的作业
   ↓
AI 识别完 → 错题出现在「识别出的错题」区
   ↓
状态：待审核（🟡）
   ↓
家长点 ✓ 正确 / ✗ 识别有误
   ↓
所有错题审完 → 点 ✓ 审核完成并入库
   ↓
状态：已入库（✅） → 错题自动进复习队列
```

### 4.2 复习（每天 1 次）

```
家长打开「复习」页
   ↓
看到今日待复习（红字）→ 让孩子口头/笔头重做
   ↓
点 👁 看答案核对
   ↓
判对/判错
   ↓
题目滑入「今日已复习」
   ↓
下次复习日期自动排上（语文+2/7/30/30 天）
```

### 4.3 流转（不会判时）

```
打开某次打卡的详情
   ↓
底部「⚙ 处理动作」→ 填写意见 → ➡ 流转给妈妈
   ↓
妈妈那边 WorkBuddy 看到任务 → 接手处理
```

### 4.4 期末复习

```
打开「知识点」→ 🗓 学习计划
   ↓
看「薄弱点 TOP 5」+ 未来 7 天复习日历
   ↓
按日历每天做，不会多不会少
```

## 5. 撤回机制（防误操作）

**所有确认按钮都配有撤回**，不必紧张：

| 操作 | 撤回方式 |
|---|---|
| 今日打卡/无任务 | 卡片上的 `↩ 返回` |
| 错题 ✓ 正确/✗ 驳回 | 该错题下方的 `↩ 撤回审核` |
| 审核完成入库 | 任务详情底部 `↩ 撤回最近动作` |
| 打回重跑 | 同上 |
| 流转给妈妈 | 同上 |
| 接手 | 同上 |
| 复习答对/答错 | 复习卡 `↩ 撤销本次` |
| 删除照片 | 直接撤回（不再二次确认） |

撤回会写入操作日志，可以从时间线追溯谁撤回过什么。

## 6. 给小孩的简易说明（迦一版）

> **迦一：**
> 1. 每天做完作业，就用手机打开链接
> 2. 找到今天那项（听写/校内精练/作文/学而思），点 **☐ 今日完成**
> 3. 拍 1~3 张作业照片
> 4. 妈妈或爸爸会在电脑那边看到，帮你整理错题
> 5. 复习的时候你会看到一些红字卡片，那就是你以前错的题。**重做给爸妈看**就行，对了就行，错了没关系
> 6. 如果今天没有某项作业（比如今天不写听写），就点 **— 今日无任务**
> 7. **不喜欢的卡片都可以点 ↩ 返回**，不要怕点错

## 7. 常见疑问

**Q: AI 识别错了怎么办？**
A: 错题卡片有「✗ 识别有误」按钮，填一下哪里错了，会自动开新版本让 AI 重跑。

**Q: 孩子明明答对了，怎么变错题了？**
A: 错题入库是 AI 判的，你点详情里 `↩ 撤回审核` 把它退回待审，再点 `✗ 识别有误` 写意见。

**Q: 错题太多记不住？**
A: 不用记。看「🔥 知识点热力图」就行，颜色越红越多错，颜色越绿越少。

**Q: 一个学期要保存多少数据？**
A: 一张作业照片 1~3MB，错题文本几 KB。按每天 5 项作业算，一年约 5~10GB，10GB 额度够用 2~3 年。

**Q: 数据会丢吗？**
A: ⚠️ **目前有风险，尚未闭环，务必看完这条。**

数据库（`kanban\data\kanban.db`）和作业照片（`kanban\uploads\`）**都只存在应用运行的服务器本地磁盘上**，**没有自动备份到项目资产（云盘）**。若服务器环境被重置或回收，数据会丢。

**现在就该做的**：定期复制 `data\` 和 `uploads\` 两个目录到安全位置。

**Q: 复习节奏太频繁/太松？**
A: 数据库 `review_rules` 表里改 intervals 即可：
```sql
-- 语文：第 2/7/30/30 天
UPDATE review_rules SET intervals='[2,7,30,30]' WHERE subject='语文';
-- 数学：只练 2 次间隔长
UPDATE review_rules SET intervals='[1,30]', max_stages=2 WHERE subject='数学';
```

## 8. 系统限制

- **AI 不能直接读图**：当前模型没有视觉能力，所以"识别作业"是用户在对话里 @助手 触发
- **不传视频**：视频类学习资料只提取文字，不上传原视频
- **看板是单一数据源**：WorkBuddy 原生看板只做入口，不在这里做内容

## 9. 进阶：术语表

| 术语 | 含义 |
|---|---|
| **打卡** | 标记今天做了某项作业 |
| **checkin** | 数据库里的一次打卡记录 |
| **wrong_question** | 错题，关联到某次 checkin |
| **ai_run** | AI 识别的一个版本，v1/v2/v3 |
| **review_schedule** | 错题的复习计划，next_review_date 决定什么时候再出现 |
| **rerun_requested** | 打回重跑，等 AI 重新识别 |
| **transferred** | 流转中，等另一位家长接手 |
| **overdue** | 复习日已过但还没做 |
